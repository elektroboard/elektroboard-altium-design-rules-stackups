# Stackup Templates

These files intentionally avoid manufacturer-specific laminate names such as
2313 or 2116. They model generic FR-4 and are intended as project-starting
templates.

For controlled impedance, replace this template with the selected
manufacturer's actual construction before final routing/fabrication review.


## ⚠️ Fabrication Warning

**DO NOT RELEASE TO FABRICATION USING THESE STACKUPS WITHOUT MANUFACTURER VERIFICATION.**

These are generic nominal templates, not manufacturer-approved constructions.
For production, confirm the actual core/prepreg materials, finished thickness,
copper thickness, Dk, impedance and tolerances with the selected PCB manufacturer.
